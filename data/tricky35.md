# Tricky35: длинные диалоги с несколькими ловушками

35 новых синтетических сценариев T001–T035: 20 счетов, 10 переводов себе и 5 none.
Разбиение dev=18/test=17 задано до прогонов; модели для подготовки данных не вызывались.
Эталоны написаны вручную, источники — только реплики пользователя. Реквизиты вымышлены.
Это стресс-набор, а не репрезентативная выборка обращений и не доказательство качества модели.
Строгая оценка источников требует ровно указанных ID; альтернативный достаточный набор ID может отличаться.
При исправлении позиции evidence объединяет актуальные источники её атрибутов, без архивных значений.
При скидке на весь счёт цены в строках сохраняются; скидка применяется только к amount_rub.
Для missing evidence пуст; факт отзыва значения описан в диалоге, но отсутствующее значение не заполняется.
Проценты НДС берутся только из явно указанной актуальной ставки; единицы копируются в исходной форме.
Длина диалогов: 1464–1737 символов, в среднем 1653.
