# Jev prompts v1

Снимок текущих промптов перед последующими изменениями. Точное время создания,
контрольные суммы и версии зависимостей записаны в `manifest.json`.

- `verification.py.txt` — вопросы, критерии и сборка проверки полей.
- `field_rules.py.txt` — общие правила полей и примеры.
- `document_type.py.txt` — классификация документа и причин отсутствия запроса.
- `form_templates.json` — описания полей счёта и перевода.
- `resolved_rules.json` — готовые тексты правил и вопросы классификации для чтения.
- `context/` — зависимости схем и проверки источников, влияющие на запросы.

Это архив, рабочий код его не импортирует. `.env`, ключи, пользовательские
диалоги и результаты платных запросов в снимок не включены. Промпт извлекающей
LLM (`src/llm.py`) в эту версию Jev не входит; общие правила полей сохранены.

## Как вернуться к формулировкам v1

1. Найдите нужные правила в `resolved_rules.json` или архивной копии исходника.
2. Сравните их с текущими файлами по путям из `manifest.json`.
3. Перенесите нужные тексты, примеры и условия сборки в рабочий код.
4. Запустите связанные тесты классификации, верификации и ремонта.

Не заменяйте Python-модули целиком без проверки: вместе с промптами это может
откатить исправления логики. `context/` сохранён для понимания прежнего поведения,
а не для автоматической замены рабочего кода. Версию v1 не редактируйте — для
следующего снимка создайте отдельную папку v2.
