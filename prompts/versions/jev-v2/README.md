# Jev prompts v2

Снимок промптов Jev, полученный из v1 правками формулировок и условий сборки
запросов (нормализация единственного числа в описаниях позиций, правило
recipient_relation и др.). v1 остаётся неизменной точкой отсчёта для сравнений.
Время фиксации — updated_at_utc в manifest.json; там же контрольные суммы файлов
снимка и версии зависимостей.

- verification.py.txt — вопросы, критерии и сборка проверки полей.
- field_rules.py.txt — общие правила полей и примеры.
- document_type.py.txt — классификация документа и причин отсутствия запроса.
- form_templates.json — описания полей счёта и перевода.
- resolved_rules.json — готовые тексты правил и вопросы классификации для чтения.
- context/ — зависимости схем и проверки источников, влияющие на запросы.

Это архив, рабочий код его не импортирует. .env, ключи, пользовательские
диалоги и результаты платных запросов в снимок не включены. Промпт извлекающей
LLM (src/llm.py) в эту версию Jev не входит.

Файлы v2 правились вручную на основе v1, поэтому sha256 в manifest.json — это
суммы файлов снимка, а не какой-либо версии src. Путь source указывает, из какого
модуля взят файл.

Версии v1 и v2 не редактируйте: для следующего снимка создайте новую папку.
